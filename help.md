### Set up your ElevenLabs API key

1. Sign in at [elevenlabs.io](https://elevenlabs.io).
2. Open **Developers > API Keys** and create a key.
3. Allow it **Text to Speech** and **Voices (read)**.
4. Paste it into the **ElevenLabs API Key** field, then continue.

Every character you read uses credits from your ElevenLabs plan.

### Use it

- **Read Selection** reads whatever text is selected in the front app. Run it again to stop. Give it a hotkey in Raycast for the best experience.
- **Read Clipboard** reads the text you last copied. It works when an app blocks text selection.
- **Select Voice** lets you browse and preview voices. Press `↵` to use one, `⌘↵` to hear it.
- **Stop Reading** stops the audio from anywhere.
